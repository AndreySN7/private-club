Приложение на Spring Boot с базой данных PostgreSQL в Docker и REST-контроллерами.

Закрытый клуб делает вход по одноразовому QR-коду. Когда гость прикладывает QR-код, в приложение приходит UUID участника.

Логика такая:

если такой UUID есть в базе — возвращаем информацию об участнике (ФИО), а его QR-код (UUID) сменяется на новый — старый больше не сработает (он «одноразовый»); если UUID не найден — вход не разрешён. Также нужно предусмотреть добавление, изменение и удаление участников и QR-кодов через REST-контроллеры.
